# Security

Report a vulnerability in a generator privately through
[GitHub private vulnerability reporting](https://github.com/kadet-hub/generators/security/advisories/new),
or write to security@kadet-hub.org. Do not open a public issue for it.

A generator that behaves maliciously, or a problem in the marketplace
itself (the gate, the sandbox, the release workflow), goes to
[kadet-hub/registry](https://github.com/kadet-hub/registry/blob/main/SECURITY.md).

## Supported versions

The newest release of each generator gets security fixes. Releases are
tagged `<generator>-v<semver>`.

## Handling

This repository is maintained on a best-effort basis, with no response
time or fix deadline. A fixed vulnerability is published as a GitHub
security advisory naming the generator, the affected and fixed versions
and a CVSS score.
